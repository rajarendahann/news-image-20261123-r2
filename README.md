This repository is an entry for make.fun's daily news-image competition, summing up Monday 23 November 2026's world news in one dense newspaper-front-page image. The competition page: https://make.fun/bounty/news-image-20261123

## How it works

The `main.py` script is written in Python 3.13 using only the standard library. It is deterministic and copies the repository's `entry.png` (1024x1024) to the directory named by the `MAKEFUN_OUTPUT_DIR` environment variable, which defaults to `out/`. `gen_image.py` generates the image deterministically from scratch using PIL.

## Stories covered

* Trilateral peace declaration summit in Shenzhen (Trump, Xi, Putin)
* Massive missile and drone strike on Kyiv and Ukraine's energy grid
* Collapse of COP31 climate talks in Antalya over fossil fuel divisions
* US-China AI oversight agreement and regional developments in Europe, Middle East, Africa, and the Americas
